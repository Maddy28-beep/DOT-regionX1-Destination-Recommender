# Further real destinations: research batch 3

Source-backed existence does not establish current opening, safe access, a verified map pin, a published rate or permission to republish a photograph. Those checks remain separate. In particular, a tourism directory or Adventure Challenge entry is not an accreditation certificate. Do not use an unrelated photo just to complete the batch.

## Held out of this batch

- Dats Cave and Asbang Faksol Cave remain the two pending candidates from batch 2, not new discoveries in this count; accurate individual photographs are still unresolved.
- Maxima AquaFun: historic travel sources exist, but a more recent closure report requires direct operator confirmation before recommending it as visitable.
- Saliducon Cave: existence is well documented, but a guide-page mirror includes a temporary suspension advisory after an earthquake. Current official access must be confirmed before presenting it as open.
- Angel's Flower Garden and Nursery: the provincial page's main description and map point say Mapawa/Maragusan, while its contact-location block says Pantukan. Resolve the inconsistent address before import.
- Little Boracay in Santa Maria is already represented by the Tuka Beach record; not counted again.
- Amacan Crater was held pending exact visitor location, access and separation from the Lake Leonard/thermal-area records.

## Implementation boundary

The import retains the existing unconfirmed information icon, creates no accreditation record, preserves current listing and planner implementation, leaves unknown values blank and excludes unverified visit details from itinerary generation. Photo publication rights remain separate from local testing permission.

## Applied locally

All 15 were added through `destinations:import-third-real-local --apply`. Source files, original URLs, credit lines, aliases and hashes are in `database/data/listing-photos/real-destinations-batch3-2026-11-19/manifest.json`. Exactly one real photo is attached to each new listing. Photos are recorded for local testing only, with source marks preserved. New Barili's older photograph is credited as a historical view. A Jorge Town collage was rejected and replaced by one photograph of its garden bridge. Mount Kalilongan is stored as Mount Karilongan, following the community source's spelling and photographed entrance sign; both spellings are aliases. The trail entrance photo is from EGIP Foundation via iVolunteer Philippines.

Duplicate protection covers normalized names, known aliases, slugs, destination ambiguity and matching accommodation records. The command refuses production use and defaults to a dry run. All new entries retain the existing excluded itinerary role while operational visit details are unverified. No shared application, planner, listing, sharing or approval code was modified.

Validation: 13 focused import, photo and filter tests passed with 508 assertions. All 15 detail responses returned HTTP 200 with existing public photo files. Two unrelated pre-existing PHPUnit metadata deprecation warnings remain.
